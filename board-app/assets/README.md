# Storybloq brand assets

These unmodified Latin WOFF2 subsets and themed name-and-logo lockups are the exact files used by the website build. The manifest records their source paths, byte sizes and SHA256 hashes. Inter supplies body text, controls, identifiers and dates; Fraunces supplies editorial headings. System fallbacks cover characters outside the Latin subsets.

Each font retains its complete upstream SIL Open Font License 1.1 notice. The manifest additionally retains the copyright from the actual font name table: the cached Inter and Fraunces binaries have different copyright years from the current upstream notices. Both notices are included in the generated resource. Font licenses remain separate from the repository's license. Original Storybloq lockups retain the repository license.

The build and fixture preview embed the same validated pack directly into HTML. No font service or additional resource domain is needed. Update the manifest alongside any intentional asset replacement; mismatched bytes fail the build. Builds never rewrite the source assets.
